# Website-Bilder für P34nuts

Lade neue Bilder, die später auf der Website eingesetzt werden sollen, in diesen Ordner.

## Upload-Pfad auf GitHub

`p34nuts-official-website/client/public/uploads/page-images/`

## Hinweise

- Verwende möglichst sprechende Dateinamen, zum Beispiel `press-berliner-zeitung.jpg` oder `all-frames-neues-cover.webp`.
- Erlaubte Formate: `.jpg`, `.jpeg`, `.png`, `.webp` und `.svg`.
- Für Fotos und große Hintergründe ist `.webp` bevorzugt.
- Lade möglichst die Originaldatei in guter Qualität hoch.
- Schreibe in deine Nachricht anschließend den exakten Dateinamen und wo das Bild eingesetzt werden soll.
- Bilder in diesem Ordner werden nicht automatisch auf der Seite angezeigt. Ich binde sie erst nach deiner Anweisung in die gewünschte Sektion ein.

## Weitere Unterordner

Wenn mehrere Bilder zu einem Bereich gehören, kannst du optional Unterordner verwenden, zum Beispiel:

- `press/`
- `all-frames/`
- `hero/`
- `release/`
- `archive/`
